# CMTKB — site gratuit

Cette première maquette est un site statique, donc elle peut être hébergée gratuitement avec GitHub Pages.

À personnaliser :
- remplacer le logo CMTKB ;
- confirmer les horaires et tarifs ;
- ajouter le vrai lien de licence ;
- ajouter téléphone, email et réseaux sociaux ;
- ajouter photos et palmarès ;
- ajouter les mentions légales et la politique de confidentialité avant mise en ligne.

Aucune information sensible d'adhérent ne doit être publiée sur le site.
