CMTKB — V1 simple à installer
1. Envoyer index.html, style.css et script.js à la racine du site.
2. Aucun dossier assets n'est nécessaire : les visuels sont intégrés directement dans index.html.
3. Le logo intégré est la version officielle CMTKB validée (deux boxeurs, CHIRONGUI / CMTKB / MUAYTHAI • KICK-BOXING).
